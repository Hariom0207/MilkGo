# MilkGo

MilkGo is a software for the dairy vendor who manages the distribution of milk packets to retailer shopkeepers — for maintaining dairy sales, purchase, customer accounting, and other analysis.

Dairy management dashboard UI.

## Stack
- Vite + React + TypeScript
- Tailwind CSS v4
- React Router
- Lucide icons

## Run
```bash
cd d:\P1\MilkGo
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).
